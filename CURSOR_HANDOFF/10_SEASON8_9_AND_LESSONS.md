## 2. TikTok delivery format (new default)
* Master render stays 1080x1920 (all art/camera coordinates are authored for it). `run_episode.ps1 -Tiktok` then makes `...-576x1024.mp4` with `ffmpeg -vf scale=576:1024:flags=lanczos,format=yuv420p -c:v libx264 -preset slow -crf 17 -c:a copy -movflags +faststart` and delivers: main file + `COVER.png` at **576x1024** into `Content Creation\Videos`, the 1080x1920 master into `Videos\HD_1080x1920\`.
* TikTok UI safe zone: the bottom ~20 % (and the right edge) is covered by the app. Since ep36 the captions sit at `#capsB{top:1250px}` (words ≈ y 1320-1480) and the end-card sticker at `bottom:380px` (done once in `mk_template_s6.py` for `n == 36`, inherited by every later episode). Keep important faces above y≈1250 in close-ups.
* Loudness −14.2 LUFS, 30.0 s, 30 fps, AAC (unchanged).

## 3. New tools (all in `hyperframes/`)
| tool | what it does |
|---|---|
| `node preflight.cjs N` | page errors, timeline ≤ 30.5 s, orphan tweens, **camera moves must not overlap**, **the speaker's face must be on screen and ≥ 75 % uncovered at the start of each line** (prints who covers it) — run it before every render |
| `node selcheck.cjs N` | static check (no browser): every `'#id'` / `'.class'` used by `_initN/_bodyN` exists in the built page |
| `python timings.py N` | prints start/duration/word offsets of every line (use these to place cues; **`W(line,i)` is 0-based**) |
| `python voice_lessons.py` | lists lines the ASR heard imperfectly in all `tts.out` files |
| `music_s8.py` (`adv_music`) | segment-based music generator (intro/magic/hush/drive/build/finale) used by `_audioN.py` |
| `mk_s8_setup.py`, `mk_s9_setup.py`, `run_tts_s8/9.ps1`, `run_queue_s8/9.ps1` | scripts, resumable voice chains and render queues for the two seasons |

## 4. Rules learned (apply to every new episode)
1. **Script for the voice engine:** 11 lines, 4-7 words, ≈ 50-60 words in total so line 11 ends ≤ 25.5 s (the pauses between lines add ≈ 0.7 s each; slow voices like Grandma at speed 0.85 cost seconds → use 0.93). Avoid words Whisper garbles ("canyon", "creaked", stand-alone "Aww!"). If the log prints `WARNING: line 11 ends after 26.6 s`, shorten lines and regenerate only the changed lines (delete `assets/vo/lineN.wav` + `words.json`).
2. **Staging:** never put a front-row character in front of the next speaker's face. Use `preflight` after every change of marks. Fixes are always moves (marks), never hiding someone.
3. **Never animate `y` on a group that has a `translate()` attribute** (planks, palms): wobble an inner group.
4. **One camera move at a time on `#cam`**: a `camTo` that starts before the previous one ends makes a visible jump.
5. **Index convention:** `W(line, i)` = start of word *i* (0-based) of that line; `L[n]`/`DU[n]` are 1-based lines.
6. New shared helpers go in `_initN.js` (they accumulate into later templates); `_bodyN.js` constants do **not** accumulate.
7. Heavy jobs and other sessions: the PC (2 cores, ~7.7 GB, 16 GB commit) is shared. Whisper dies with `mkl_malloc` when commit runs out. Check free commit (`Win32_OperatingSystem.FreeVirtualMemory`) before TTS/renders, run one heavy job at a time, launch long jobs detached with `Invoke-CimMethod Win32_Process Create`, never kill processes you did not start, and tell peers before a 1-hour render.
8. The PowerShell tool has no heredocs: write files with the editor tool or use the Bash tool for Python one-liners.

9. **Name clashes with the shared template head** make the whole page fail (`Identifier 'X' has already been declared`): check new top-level names (`PILE_HTML`, `steam()` already existed) and element ids (`#pile`, `#pileW`) with `grep -c` in the previous episode's `build/template.tpl` before using them.
10. **Characters need `EYE[id]`/`EH[id]` before `ECAM(id,…)`**: measure with `node eyeprobe.cjs N id …` (Munch/Pebble = `[0,-544]`). Only Flapjack-type rigs (pan, wd, gma, cz1-3) have `#idShake`; the rock rigs and Bo do not (tumble the `#idSq` group instead).
11. **Cross-fading two backgrounds**: fade the new one in ON TOP and only then hide the old one (fading both shows the kitchen set behind them).
12. **Shared PC etiquette**: peer sessions ask for exclusive windows (renders, mixes, TTS). Stop only your own queue parent and the render you just started, wait for their "mix done" message, then restart the resumable queue. Run queues as visible background tool jobs behind a `FreeVirtualMemory` gate; hidden detached nested-powershell launches can hang with 0 CPU.
13. **Pitched/child voices (Pebble) garble sibilants and exclamation words**: "Wow!", "Beach!", "Splash!", "Sun!" came out wrong. Reword to plain verbs ("Look! A pancake tower!", "Play! Play! Play!"), listen to the ASR line in `tts.out`, and regenerate only that line.
14. **Props that must read from far away need size, not detail**: the first wave looked like a flat block (redesigned with crest + foam), towers hidden behind builders (scaled up), the castle and welcome sign hidden by the crowd (raised/enlarged). Always snapshot at the moment the prop is the story, not only at line starts.
15. **`hyperframes snapshot`/renders are Chrome jobs**: do not run them while a peer mixes/renders (it slowed the peer's mix once); `node eyeprobe.cjs N id…` (headless, short) is fine but still check free commit first. A `camTo`'s `ECAM(p,…)` needs `EYE[p]` for every new rig (Munch/Pebble = `[0,-544]`).
16. **A caption can get stuck on screen**: when Whisper merges a word (`s == e`, e.g. "HERE" in ep58 line 6) the chunk's hide-time lands before its show-time and the word stays forever. After every TTS run scan `words.json` for words with `e-s < .08` at a chunk boundary and give them .14 s (edit `s`/`e` of that word and the next word's `s`), then rebuild. (Short words inside a chunk are harmless.)
17. **Exact motion = setter-driven tweens**: swings, flights, somersaults are computed in `proxyTween(t0,dur,u=>{…})` that calls `gsap.quickSetter` setters (the same trick as the depth sort); never rely on `onUpdate` (it is skipped when the page seeks). Pose maths: SVG rotation `r` (clockwise positive) turns a rig's up-vector to `(sin r, -cos r)`; a pendulum with bar angle `a` (positive = bar to the right) has rope rotation `-a`, the hanging body is rotated `-a` about its feet at `P+(LR+HS)(sin a, cos a)`; a body-centre pose uses `feet = centre - Hc*s*(sin r, -cos r)`.
18. **Shared-head names already taken** (the page then fails with "Identifier … already declared"): `place`, `CX`, `bx`, `by`, `zx`, `zy` (use `placeAt`, `P56`, `bhx`, `bhy`, `zhx`, `zhy`). Run `node chk_js.cjs toonN` after every build.
19. **Never batch-edit with a PowerShell helper taking `@(@("old","new"))`** — PowerShell flattens a one-element array of pairs and the helper then replaced every `f` with `u` in `_init56.js` (restored from the intact built `toon56/index.html`: the template contains every init/def, so a built page is a backup). Use the Edit tool or Python for multi-line replacements.
20. **Short scripts**: when line 11 ends before ~24 s the end card would sit on screen for 6-7 s; `GAPS` in `mk_s6_setup.py` (`plan N`) stretches the pause between lines (default .36 s, S12 eps 57/58/60 use .62 s) without regenerating the voices. `python mk_s12_setup.py N` rewrites only that episode's `tts.py`; delete `assets/vo/lineK.wav` + `words.json` to regenerate one line.
