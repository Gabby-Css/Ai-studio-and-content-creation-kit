# References and guides

These written references describe editing techniques, visual systems, and workflow options. They are study material, not a guarantee of quality, performance, asset availability, or permission to reuse another creator's work.

Third-party reference footage, reference thumbnail images, and reference plates are omitted. Add your own owned or appropriately licensed files; see `references/ADD-YOUR-OWN-LICENSED-MEDIA.md` and `LICENSES.md`.

## Choose a craft guide

| Deliverable | Read |
|---|---|
| Graphics over or replacing footage | [Motion-graphics reference systems](motion-graphics-reference-systems.md) |
| Generated cinematic shots | [AI-film cinematic pipeline](ai-film-cinematic-pipeline.md) |

The visual-system notes can help avoid repetitive layouts. The film guide covers location, character, and shot planning. Apply the relevant ideas, then judge the actual output rather than assuming that following a pattern ensures a result.

## Production loop

Brief → select a visual approach → prepare authorized narration/assets → render and assemble → inspect frames, motion, sound, and caption timing → revise → review the final export.

Use `pipeline/STUDIO-ROUTER.md` to select tools and `pipeline/STUDIO.md` for the process. A research score or heuristic is not measured viewer attention, and a source listing is not an installed dependency or a license grant.
