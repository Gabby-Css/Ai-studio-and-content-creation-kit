# 🎬 MEGA-PROMPT — Learn From a Transcribed Video

Paste a YouTube/reel **TRANSCRIPT** at the bottom. This runs the studio's transcript-learning loop: DIGEST the craft →
COMPOUND it into the craft library → OUTPUT a ready-to-shoot concept applying it. The persistent version writes a
playbook, appends `pipeline/VIDEO-CRAFT-LEARNED.md`, and records an ingestion receipt with performance still unverified:
`node transcribe/learn-from-transcript.cjs <file.txt> --niche="..."`.

Use `--prompt-only` to export a prompt without calling a provider. After reviewing a generated
digest, import it with `--digest=<reviewed.md>`. Configured model calls may incur charges.

## Role
You are a world-class short-form + YouTube director/editor. Study the transcript for **TRANSFERABLE CRAFT — never the topic.**

## Run these 4 phases

### 1 · DIGEST — extract the transferable craft
FORMAT & PACING · **HOOK** (quote the first 3–5s + name the technique) · STRUCTURE (beat-by-beat) · RETENTION TACTICS
(open loops / pattern interrupts / re-hooks / but-so momentum) · SCRIPTING PATTERNS (rhythm, specificity, proof framing) ·
CTA STYLE · **TRANSFERABLE RULES:** 5–10 crisp "when X, do Y because Z" rules.

### 2 · RECURSIVE-LEARN — compound it
Compare against what we already know (`pipeline/VIDEO-CRAFT-LEARNED.md` + `pipeline/MONTAGE-CRAFT.md`). State the **delta**: what's NEW vs
confirms vs contradicts prior lessons. Only NEW/updated rules get added — don't restate the base.

### 3 · EVIDENCE — record a testable hypothesis
For each rule, tag the impact axis it should move (hook-retention / watch-time / shares / CTR) so it can be **graded later
against actual audience outcomes** where available. Keep optional research-model scores separate from measured performance. Prefer rules confirmed across multiple studied videos;
demote ones a later video contradicts.

### 4 · APPLY — draft a concept to review
Produce a **READY-TO-SHOOT** concept for the requested niche *(default: practical AI tools for local businesses)*:
**TITLE · HOOK** (exact first line) **· STRUCTURE** (beats w/ approx seconds) **· FULL SCRIPT/VO · ON-SCREEN + EDIT NOTES**
(cuts, captions, b-roll) **· CTA** — naming which learned rule each choice applies. Then a **thumbnail concept + 3 title options**.

## Studio routing (how to actually make it)
Choose configured tools for the brief: **Hyperframes / Remotion / Unreal** or an authorized hosted generator → own recording or configured voice option → assembly → manual review → revision. Optional providers and research scorers require separate setup, rights review, and possibly payment; hosted calls receive submitted content. No score guarantees retention.
